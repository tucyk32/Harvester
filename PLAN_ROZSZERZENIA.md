## 🏗️ **Architektura Techniczna**

### **Schemat Unifikowany**
```json
{
  "id": "unique_identifier",
  "start_jd": 2234567.5,
  "end_jd": 2234567.5,
  "am_day": 513403.0,
  "category": "POLITICAL|CULTURAL|SCIENTIFIC|ASTRONOMICAL|BIOGRAPHICAL|ECONOMIC|NATURAL",
  "subcategory": "specific_type",
  "title": "Event title",
  "description": "Detailed description",
  "location": {
    "name": "Place name",
    "coordinates": [lat, lon],
    "modern_equivalent": "Modern location"
  },
  "participants": ["Person1", "Person2"],
  "sources": [
    {
      "type": "primary|secondary|tertiary",
      "title": "Source title", 
      "url": "source_url",
      "reliability": 1-5
    }
  ],
  "tags": ["tag1", "tag2"],
  "temporal_precision": "day|month|year|decade|century",
  "certainty": 1-5,
  "language": "source_language",
  "related_events": ["event_id1", "event_id2"]
}
```

### **Baza Danych**
- **Primary**: PostgreSQL z rozszerzeniami GIS (PostGIS)
- **Search**: Elasticsearch dla pełnotekstowego wyszukiwania
- **Cache**: Redis dla szybkich zapytań
- **Files**: MinIO/S3 dla obrazów i dokumentów
